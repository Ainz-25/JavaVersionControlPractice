# Documentation Practice



Aplikasi konsol Java sederhana yang dibangun untuk mendemonstrasikan praktik version control dengan Git dan dokumentasi proyek.



## Fitur Utama

- Menampilkan pesan teks konsol sederhana menggunakan Java.

- Terintegrasi dengan sistem kontrol versi Git dan GitHub.



## Prasyarat

- Java Development Kit (JDK) 17 atau yang lebih baru

- Git



## Cara Menjalankan Program

  Kompilasi file Java:



  `javac Main.java`
